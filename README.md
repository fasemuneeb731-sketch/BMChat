# BM Chat

**BM Chat — Private team communication for businesses.**

This repository contains the BM Chat one-page website.

## Publish the website with GitHub Pages

1. Open the repository **Settings**.
2. Open **Pages** from the left menu.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**.
5. Save. GitHub Pages will publish the site and show its public URL in the Pages section.

The website is self-contained in `index.html`; no external screenshot folder is required.

## Publish the Windows download

1. Open the repository's **Releases** page.
2. Select **Create a new release**.
3. Use tag `v1.0.0`.
4. Set the release title to **BM Chat for Windows v1.0.0**.
5. Attach the file named `BMChat-Windows.zip`.
6. Publish the release.

The website download button points to:

`https://github.com/fasemuneeb731-sketch/BMChat/releases/latest/download/BMChat-Windows.zip`

The download button will work after that exact asset has been uploaded to a published release.

## Product details

The app welcome screen describes office-network use, offline operation on the office network, and local office-hub data storage. Confirm the final app package on a separate Windows PC before distributing it widely.

BM Chat is presented as free to use, with no ads or subscription fees.
